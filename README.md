# 🧠 Meu Segundo Cérebro | Notas do Obsidian

Este repositório é o meu sistema de gerenciamento de conhecimento pessoal (**PKM**). Aqui eu documento meus estudos, reflexões, snippets de código e conexões entre diferentes áreas do conhecimento, utilizando a filosofia do [Obsidian](https://obsidian.md/).

---

## 📂 Organização (Método PARA)

Sigo uma estrutura lógica para evitar o caos informacional:

* **📥 00_Inbox**: Notas rápidas, capturas brutas e ideias que ainda precisam de triagem.
* **🏗️ 10_Projetos**: Notas com prazo determinado e objetivos específicos (Ex: "Curso de Python", "Reforma do Quarto").
* **📂 20_Areas**: Temas contínuos que exigem manutenção constante (Ex: Finanças, Saúde, Carreira).
* **📚 30_Recursos**: Minha biblioteca de interesses, artigos, livros e referências úteis.
* **🗄️ 40_Arquivo**: Projetos finalizados ou temas que não são mais prioridade no momento.
* **⚙️ 90_Meta**: Templates, arquivos de configuração e anexos (imagens/PDFs).
